A simple and interactive number guessing game developed using Python. This project was created as part of my journey into Python programming and serves as my first step toward building practical programming projects.

Project Overview:
Number Guessing Game is a beginner-friendly Python application where players attempt to guess a randomly generated number.
The game provides feedback to guide players toward the correct answer, making the experience simple and engaging.

 Key Features:
- Random number generation
- Interactive user input
- Higher or lower hints
- Score tracking
- High score management
- Simple and user-friendly interface

 Technologies Used:
- **Programming Language:** Python
- **Data Storage:** JSON

 Project Structure:
- `main.py` – Main entry point of the application
- `game.py` – Core game logic
- `gui.py` – Graphical user interface
- `ui.py` – User interface components
- `config.py` – Game configuration
- `storage.py` – Data storage management
- `achievements.py` – Achievement management
- `highscore.json` – High score data
